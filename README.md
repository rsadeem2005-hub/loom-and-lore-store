# Loom & Lore Store

Static storefront for the Loom & Lore Klaviyo portfolio project.

## Deploy to Vercel
Upload this folder to Vercel or import it through GitHub.

- Project name: `loom-and-lore-store`
- Framework preset: Other
- Build command: leave empty
- Output directory: root / leave empty

Files:
- `index.html` — storefront and cart
- `checkout.html` — checkout simulation

The checkout does not process real payments.
